# Historical COMETS design

These manifests belong to an older pool/community enumeration produced by the retired `design_communities.py`. They are retained as historical simulation inputs and are not generated from, or representative of, the current manual pool-v5 YAML.

Do not use `manifest.tsv` as the current 14-member experimental design. Any future COMETS design should start from `panel/pool_v5_panel.yaml` and an explicitly documented process medium; the existing configuration is fully aerobic and does not resolve alternative-acceptor/product-consumption tradeoffs.
