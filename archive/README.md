# Archive

Nothing here is broken or wrong. It is here because the question it answers is no longer
the question being asked. Each entry says what it concluded and what superseded it, so it
can be picked back up rather than re-derived.

## `d_lactate_guild/`

**Status: abandoned on cost, not on science.**

A complete D-lactate guild screen — every member a producer, redundant rather than
divided by labour, following the LS30 crude-glycerol enrichment precedent. It was dropped
because the downstream separation protocol for D-lactate is too expensive to justify at
this project's scale, not because the guild failed. The guild it assembled is real and
the screen behind it is the most careful annotation work in the repo.

```
screen_d_guild.py     the screen; 384 genomes → guild membership
d_guild_bench.py      benching and panel emission
d_guild_panel.yaml    the resulting panel (generated by d_guild_bench.py --emit-panel)
results/              everything the above produced, including its own ANI, model gate,
                      curation and virulence output
```

**`guild_diversity.py` now lives in `physiology/`.** It was written for this
guild but the question it answers — what distinguishes members of a pool that are all
capable of the same thing — is the one pool v5 faces with fourteen producers. It now reads
KEGG-ortholog profiles for any genome list and writes to `results/pool_v5/`.

## `pool_v2_candidate_panel.yaml`

The former root `candidate_panel.yaml`, retained as the explicit input for the historical
pool-v2 work. It is superseded by `panel/pool_v5_panel.yaml` and must not be used as the
current staged-input definition.

**Worth reading even though it is archived.** `screen_d_guild.py`'s module docstring
catalogues the annotation traps in this library, each found by censusing the data rather
than assumed:

- EC substring collisions — `1.1.1.28` occurs inside `1.1.1.284`, `1.1.1.27` inside
  `1.1.1.271`
- gene names outliving their orthology — eggNOG emits `gldA` carrying an ABC-transporter
  KO
- L-LDH versus malate dehydrogenase, same fold and same PFAM
- the lactate racemase KO trap — the plausible K22227–K22232 range is not `lar`; K22229
  is gluconate 2-dehydrogenase
- glycerol dehydratase versus propanediol dehydratase

All of these still apply to the L-lactate screen and are respected by it.

**Two things it got right that carried forward.** First, the isomer/EC discipline: the
second digit of the EC number is the electron acceptor and it decides direction, so
`1.1.1.x` is NAD-linked and reversible while `1.1.2.x`/`1.1.5.x` hand electrons to the
respiratory chain and effectively only consume. Second, the falsification of the
producer/supporter split — supporters growing at µ 0.55–0.60 against producers at
0.117–0.129 excluded the producer ~80-fold. `results/pool_v5/SUPPORTER_EVIDENCE.md`
confirms that across 299 communities.

**One thing to know if you reopen it.** Its `d_ldh_copies` and `l_ldh_copies` columns are
annotation-level. `results/screening/ldh_calls.tsv` supersedes them with fold-gated,
reciprocal-best-hit sequence calls. For D-LDH the two agree in 367 of 384 genomes, so the
guild membership is very unlikely to change; for L-LDH they do not, and 17 genomes with
empty eggNOG files score as carrying nothing in the older table.
